# Excel VBA UserForms Collection

Excel VBA UserForms for creating interactive forms, data entry interfaces, and custom Excel applications.

---

## 📁 What is in this repository?

Here are 3 useful Excel VBA UserForm examples you can use in your projects:

### 1. [Frm_Titlebar](./Frm_Titlebar)
- **What it does:** How to display the **Maximize** and **Minimize** buttons on an Excel UserForm.
- **Files included:** Excel file (`.xlsm`) and VBA code text file (`.txt`).

### 2. [Rmv_Titlebar](./Rmv_Titlebar)
- **What it does:** How to **remove the title bar** from an Excel UserForm for a clean and modern look.
- **Files included:** Excel file (`.xlsm`) and VBA code text file (`.txt`).

### 3. [Round_UFrm](./Round_UFrm)
- **What it does:** How to create **rounded corners** for an Excel UserForm.
- **Files included:** Excel file (`.xlsm`) and VBA code text files (`.txt`).

---

## 💡 How to use

1. Download or clone this repository.
2. Open any `.xlsm` file in Excel and click **Enable Macros**.
3. Or copy the code from the `.txt` files directly into your VBA Editor (`ALT + F11`).
