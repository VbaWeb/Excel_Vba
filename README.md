# 📊 Excel VBA UserForms Collection

> A curated collection of modern **Excel VBA UserForm** customizations, Windows API enhancements, and UI tricks for building modern, interactive, and professional Excel applications.

---

## 📌 Features & Modules

| Module / Folder | Description | Includes |
| :--- | :--- | :--- |
| [📂 `Frm_Titlebar`](./Frm_Titlebar) | **Maximize & Minimize Buttons**<br>Add standard Windows maximize and minimize control buttons to an Excel UserForm using Windows API calls. | `.xlsm`, `.txt` |
| [📂 `Rmv_Titlebar`](./Rmv_Titlebar) | **Remove Title Bar (Frameless UserForm)**<br>Completely hide/remove the default window title bar for a modern, sleek, and customized interface design. | `.xlsm`, `.txt` |
| [📂 `Round_UFrm`](./Round_UFrm) | **Rounded Corners for UserForms**<br>Apply smooth curved / rounded window corners to UserForms using the Windows GDI API (`CreateRoundRectRgn`). | `.xlsm`, `.txt` |

---

## 🚀 How to Use

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/VbaWeb/Excel_Vba.git
   ```
2. **Open the `.xlsm` files** directly in Microsoft Excel (make sure to enable macros).
3. **Copy Code**: You can also open the provided `.txt` files in each folder and copy the VBA modules / UserForm code directly into your own Excel projects via the VBA Editor (`ALT + F11`).

---

## 💻 Compatibility
- **Microsoft Excel**: 2013 / 2016 / 2019 / 2021 / Office 365
- **Architecture**: Supports 32-bit & 64-bit Office (`PtrSafe` / `LongPtr` API declarations)
